# AI Best Practices: stay in the driver's seat

A one-page guide by Jonathan Bowe, shared with the FIU MSIS AI cohort in October 2026: [ai-best-practices.pdf](ai-best-practices.pdf).

It draws on how I built our group's diabetes notebook for an ISM 6644 final project with Claude Code: about 27 inputs from me across three sessions. Every line other than my advice carries an evidence key (E1, E2, ...) into an evidence appendix kept with the course project, which is not included here.

The six rules:

1. Give agents the tasks. Keep the judgment.
2. Plan the work and the checks before you prompt.
3. Treat an agent's report as a claim until it's rerun.
4. A matching number can still mean the wrong thing.
5. Try more ideas. Don't send 20 pages when 2 sentences do.
6. Let the harness carry the standards.
